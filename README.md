# 上班计薪器

一个网页版小工具:自动算出**当月到底要上多少天班、要上多少小时**(含调休补班),再按你的月薪和每日工作时间段,**实时**显示今天赚了多少、本月还剩多少没赚。

纯前端,Vite + Vue 3 + TypeScript,数据存在浏览器 localStorage,不上传任何服务器。

**在线地址**:<https://vegetable-code.github.io/workday-pay/>

## 功能

- **当月工作日与工时自动计算** — 法定假日、调休放假、调休补班全部按国务院放假安排标注,日历上一眼看清;排班工时按小时累加,半天自动折算。
- **按小时计薪** — 口径是「实际出勤工时 ÷ 当月排班工时 × 月薪」,不是法定的 21.75 天。
- **每周上班安排由你定** — 双休、单休、5.5 天(周六上半天)都能一键切换,也可以逐个星期自定义上下班时段。
- **不用打卡也会自动计时** — 到上班时间就自动开始计薪,即使忘了点按钮,上班到现在的这段时间也会自动补上;下班时间一到自动收工。
- **手动打卡随时可用** — 点「收工」冻结当日收入,点「继续上班」恢复;晚打卡不会让已经产生的收入倒退。
- **每日工作时间段** — 可配置多段(比如 09:00-12:00 / 14:00-18:00),午休不计入工资;也支持按星期单独调整。
- **入职时间** — 填了入职日期之后,入职之前的日期不计薪;当月工时按整月排班计算,入职日之前的工时计入分母但不产生收入。
- **请假按时间段登记** — 在日历里选中某天,直接填请假的开始/结束时间;每条假可以单独设「扣百分之多少的钱」,0% 是带薪假,100% 是全额扣薪。
- **请假期间不产生收入** — 请假时段从当日排班里挖掉,即使在请假时间内打卡,那一段也不会涨工资;请假条数再多也不会把时间轴压扁。
- **月历视图** — 正常上班 / 调休补班 / 法定假日 / 调休放假 / 按排班休息 / 未入职 六种状态分色,有请假的日期额外标「请」,点击任意一天查看当天时段与收入。

## 计薪口径

这套口径是本工具的核心,先说清楚避免误解:

| 项目 | 规则 |
| --- | --- |
| 当月排班工时 x | Σ 当月每个上班日的排班时长(小时),含调休补班,不含法定假日与调休放假 |
| 小时工资 | `月薪 ÷ x` |
| 本月工资 | `y ÷ x × 月薪`,其中 y = 当月实际出勤工时 + 请假中的带薪工时(小时) |
| 今日收入 | `小时工资 × 今日已出勤小时数 + 今日带薪请假小时数` |
| 请假扣减 | 请假时长与当天排班重叠的部分才计;重叠分钟数 × 扣薪百分比 ÷ 100 = 被扣掉的等效工时 |
| 请假带薪 | 重叠分钟数 × (100 − 扣薪百分比) ÷ 100 = 仍然计入工资的工时 |
| 计时区间 | 自动补卡段 `[上班时刻 → 打卡时刻]` + 手动段 `[打卡时刻 → 收工/当前]`,只与工作时段取交集,午休与下班后不计 |
| 忘了打卡 | 上班时刻到当前时刻自动补卡,收入不会因为没点按钮而少算 |
| 过去的某天 | 有打卡记录就按记录折算;没有记录则按整日工时计入(月结照发) |
| 未来的某天 | 不产生收入 |
| 休息日 | 不产生收入 |

**明确不做的**:加班费、税前税后、五险一金。都是月工资,不算这些。

> 请假只从「应出勤工时」里扣,分母 x 永远不变。也就是说请一天假不会让小时工资变高,
> 只是那段时间拿不到钱(除非那一假设成了带薪)。

折合日薪只作为展示:月薪 ÷ 当月工作日天数,方便和「别人说这个月有 21.5 天」比较,实际计算一律走小时模型。

### 每周上班安排

「设置 → 每周上班安排」决定一周里哪天上班、每天上多久,分两层:

1. **哪天上班** — 双休(周一到周五)、单休(周一到周六)、5.5 天(周一到周六,周六上半天),也可以逐个星期点「上班 / 休息」自己组合。
2. **每天上多久** — 默认用「每日工作时间段」(可多段,午休自动跳过);想给某一天单独加/减时段,用「单独调整」覆盖,点「恢复默认」撤销。

**半天按小时数自动折算**,不用手填 0.5 天。比如基础时段是 09:00-12:00 / 14:00-18:00 共 7 小时,5.5 天制式的周六取前 3 小时(09:00-12:00),折合 `3 ÷ 7 ≈ 0.43` 天。当月排班工时按天累加,周六只贡献 3 小时而不是 7 小时。

### 节假日优先级

当某一天同时涉及「国家安排」和「你的排班」时,按下面的顺序判定:

| 顺序 | 情况 | 结果 |
| --- | --- | --- |
| 1 | 调休补班日(国家安排要上班) | **上班,一整天**,使用每日默认时段,忽略当天的星期覆盖 |
| 2 | 法定假日 / 调休放假 | **休息** |
| 3 | 其余日子 | 由「每周上班安排」里勾选的星期决定 |

也就是说:**节假日和调休一律按国家安排,只有普通的周一到周日才看你的排班**。

### 打卡模型

今天**不需要**打卡才开始计薪:上班时刻一到就自动计时,到点自动收工。按钮只在你想手动干预时才有意义:

| 状态 | 按钮文案 | 行为 |
| --- | --- | --- |
| 还没到上班时间 | **开始赚钱** | 点击后从当前时刻开始计时(等到点自动计时也一样) |
| 自动计时中 | **收工** | 点击后冻结当天收入 |
| 手动计时中 | **收工** | 点击后冻结当天收入 |
| 已收工 | **继续上班** | 点击后恢复计时,继续增长 |
| 到了下班时间 | **今日已收工**(禁用) | 当天收入已经封顶为整日排班工时对应的钱 |

几个容易困惑的点:

- **忘了点开始上班不会吃亏** — 上班时刻到现在的时长会自动补进当日收入,例如 09:00 上班、10:00 才想起来点按钮,依然按 09:00 起算。
- **晚打卡不会倒退** — 已经自动补上的那段时间不会因为后来打卡而消失。
- **午休不涨工资** — 12:00-13:30 属于休息时段,工资停住不动。
- **到点自动收工** — 最后一个时段结束后工资停在整日工时对应的钱,按钮变为禁用的「今日已收工」。
- **收工是冻结不是清零** — 点「收工」后当日收入停在点击那一刻,点「继续上班」从那里接着涨。

历史日期漏打卡不影响统计,按整日排班工时补发。

### 入职时间

填写后:

- 入职之前的日期在日历上标为「未入职」,不计薪。
- 当月排班工时按**整月**计算,入职日之前的工时计入分母但不产生收入,所以那一部分工资会被扣掉。

  以月薪 ¥5,000、每日 09:00-12:00 / 14:00-18:00(7 小时)、2026 年 10 月 9 日入职、双休为例:

  | 排班 | 当月工时 x | 入职前工时 | 满勤实发 | 小时工资 |
  | --- | --- | --- | --- | --- |
  | 双休 | 126 h | 7 h(10-08) | ¥4,722.22 | ¥39.68 / h |
  | 单休 | 147 h | 7 h(10-08) | ¥4,761.90 | ¥34.01 / h |
  | 5.5 天 | 135 h | 7 h(10-08) | ¥4,740.74 | ¥37.04 / h |

- 进度条以「本月实发上限」为 100%,而不是月薪本身。
- 入职之前的月份没有工作日,累计收入为 0。

### 请假与扣薪

在日历里点中某一天,下半部分的「请假」区就能登记假条,不用去别的地方找入口。

每条假有三个信息:**时间段**(几点到几点)、**类型**(事假 / 病假 / 年假 / 调休 / 婚假 / 产假 / 其他)、
**扣薪百分比**(扣掉百分之多少的钱)。

| 扣薪百分比 | 含义 | 当月工资影响 |
| --- | --- | --- |
| 0% | 带薪假 | 工时照算,钱一分不少 |
| 50% | 扣一半 | 折算成一半的工时扣掉 |
| 100% | 全额扣薪 | 整段请假工时全部扣掉 |

扣薪百分比可以在列表里直接改数字,也可以建假时用「带薪 / 50% / 100%」快捷按钮选。

几条规则:

- **按时间段计算,不是按天** — 上午请 2 小时就只扣 2 小时,不会整天都算假。
- **只扣与排班重叠的部分** — 休息时段里的假(比如午休时间请假)不产生扣款。
- **请假期间打卡不涨工资** — 请假时段会从当天的排班里挖掉,在那段时间打卡,那一段也不计入收入。
- **时间轴上请假时段单独标出** — 时间轴里被请假的时段显示「请假」而不是「已完成」,进度填充也会把这段时间扣掉,视觉上不会把请假算成出勤。
- **全天请假不能打卡** — 整天都在请假时没有任何需要出勤的时段,「开始赚钱」按钮会禁用,并提示「今天全天请假,没有需要出勤的时段」。
- **重叠的假取扣得最多的那条** — 同一段时间既有 100% 又有 50% 的假,按 100% 算。
- **列表逐条显示,和汇总对得上** — 每一行显示「重叠时长 · 带薪时长 · 扣款」,重叠时段只归属给扣得最多的那条假,所以各行扣款相加正好等于上方汇总的扣款金额,不会重复计算。
- **本月实发上限同步下调** — 表盘的进度环以「扣除请假后的实发上限」为 100%。

举例:月薪 ¥20,000、当月排班 160 小时,请一天 8 小时且全额扣薪,当月工资就是
`(160 − 8) ÷ 160 × 20,000 = ¥19,000`,扣掉 ¥1,000。

如果这 8 小时设成 0%(带薪假),当月工资仍然是 ¥20,000,扣款为 ¥0。

请假记录存在浏览器 localStorage 里,和打卡记录一样,刷新不丢。

## 运行

```bash
npm install
npm run dev      # 开发服务器
npm run build    # 生产构建,产物在 dist/
npm run preview  # 预览生产构建
npm test         # 单元测试
npm run typecheck
```

Node 版本要求 18+(开发环境使用 Node 24)。

### 打包成单个 HTML 文件

```bash
npm run build:single   # 产物在 dist-single/index.html
```

把 CSS 和 JS 全部内联进一个 `index.html`,**零外部依赖**(不引用任何图片、字体、脚本),
传到任意静态托管就能直接用:

- GitHub Pages / Vercel / Netlify / 对象存储 COS、OSS
- Nginx、Apache、任意 PHP 虚拟主机
- 也能直接双击用浏览器打开(现代浏览器支持内联 module 脚本)

部署时把 `dist-single/index.html` 作为站点根目录的 `index.html` 即可。

> 数据仍存在浏览器 localStorage,与域名绑定。换域名相当于换了一个「浏览器」,
> 老数据不会自动迁移,需要用户自己重新填一次设置。

## 节假日数据

- 内置数据来自 [chinese-days](https://github.com/NateScarlet/chinese-days) `1.5.9`,已与国务院办公厅放假通知逐条核对,覆盖 **2004–2026** 年。
- 2026 年全年工作日 248 天,逐月为 `21 16 22 21 19 21 23 21 22 18 21 23`。
- 2027 年及以后上游尚未发布。在「设置 → 放假数据 → 在线更新」里可以按需从 CDN 拉取指定年份,拉到的数据存在 localStorage,离线也能用。

重新生成内置数据:

```bash
npm run gen:holidays
```

核对工作日天数:

```bash
node scripts/check-workdays.mjs 2026
```

## 数据持久化

所有数据都存在**这台设备的浏览器 localStorage** 里,不上传服务器。改动即时保存,刷新页面、关掉标签页、重启电脑都不会丢。

| 存储键 | 内容 |
| --- | --- |
| `workday-pay:settings` | 月薪、每日工作时段、每周上班的星期、按星期覆盖时段、入职日期、打卡记录、请假记录 |
| `workday-pay:view` | 正在查看的月份与选中的日期 |
| `workday-pay:holidays:extra` | 在线更新下载的额外年份放假数据 |

具体行为:

- **自动保存** — 月薪边打边存;日历切换的月份、点选的日期、打卡与收工记录都会立刻落盘。
- **刷新不丢** — 重新打开页面时,月薪、入职日期、查看的月份、选中的日期、当天打卡进度都会恢复,打卡计时从上次离开时继续。
- **多标签页同步** — 同时打开多个标签页时,一个标签页改了月薪或月份,其他标签页会立刻跟着更新,不会互相覆盖。
- **存储不可用时降级** — 隐私模式、站点禁用存储或配额写满时,顶部会显示告警条,数据只留在内存里,此时刷新会丢失。
- **手动清除** — 「设置 → 本地存储」可以看到存储状态;清空浏览器数据会一并清掉这些记录,换设备也不会跟随(没有云端同步)。

## 项目结构

- `src/core/` — 纯计算逻辑,不依赖 DOM,可直接单测
  - `types.ts` 类型定义
  - `dates.ts` 日期与时间工具
  - `calendar.ts` 工作日判定与月度日历
  - `schedule.ts` 每日/每月排班工时(含调休补班与星期覆盖)
  - `timeslots.ts` 时段解析、合并、重叠计算
  - `session.ts` 打卡相位判定与计时
  - `leave.ts` 请假时间段与排班的重叠切分、扣薪折算
  - `salary.ts` 核心计薪逻辑
- `src/core/storage.ts` — localStorage 安全封装(读写、损坏兜底、跨标签页同步)
- `src/core/view.ts` — 查看月份与选中日期的默认值与合法性收敛
- `src/stores/settings.ts` — 设置、打卡记录与请假记录的响应式存储(含 localStorage 持久化)
- `src/stores/view.ts` — 查看月份与选中日期的持久化状态
- `src/composables/useEarnings.ts` — 当前时刻与月度结果
- `src/components/` — 表盘、打卡按钮、时间轴、日历、请假编辑器、设置抽屉等
- `src/data/holidays.json` — 内置节假日数据(由脚本生成)
- `scripts/` — 数据生成与核对脚本
- `tests/` — 单元测试

`src/core` 里的计算全部是纯函数,`tests/` 覆盖了小时模型(y/x*z)、每周排班与半天折算、打卡计时、午休扣除、入职时间过滤、请假时段扣薪与带薪折算、调休优先级、持久化与跨标签页同步等关键口径。

## 使用

- 日历上点击任意一天,查看那天的工作时段与收入。
- 在选中日期的「请假」区登记假条,填时间段和扣薪百分比。
- 「上一个月 / 下一个月」切换查看历史或未来月份,「回到本月」返回。
- 顶部「设置」可调整月薪、每日工作时间段、每周上班安排(哪天上班 + 当天上多久)、入职日期。

## 已知边界

- 打卡记录只保留最近 120 天,更早的记录会被清理。
- 请假记录保留最近 400 天,足够覆盖跨年结算。
- 请假不区分工作日与法定节假日,只按你登记的时间段扣减。
- 计时跨天时按「当天结束」封顶,不会把加班时间算进去。
- 2027 年及以后的放假安排需要手动在线更新,内置数据暂未覆盖。
- 暂不支持大小周(隔周轮休),每周上班安排是固定的。
